The objective of this project is to build and deploy a secure task management system that demonstrates:

Backend architecture understanding

JWT-based authentication

Secure cookie handling

Database management

API design & error handling

Frontend integration

Deployment strategy

🛠 Tech Stack
Frontend

React.js

Axios

React Router

Backend

Node.js

Express.js

JWT (Authentication)

bcrypt (Password hashing)

Database

MongoDB with Mongoose

Deployment

Backend: Render / Railway

Frontend: Vercel

Database: MongoDB Atlas

🔐 Features
Authentication

User Registration

User Login

Password hashing using bcrypt

JWT stored in HTTP-only cookies

Protected routes

Secure logout

Task Management (CRUD)

Create task

View tasks (with pagination)

Update task

Delete task

Filter tasks by status

Search tasks by title
